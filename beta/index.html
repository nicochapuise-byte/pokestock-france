Installer ou mettre à jour

  1. Ouvrez cette page sur votre téléphone Android et téléchargez l’APK.
  2. Ouvrez le fichier téléchargé. Si Android le demande, autorisez l’installation depuis cette source uniquement pour ce fichier provenant de notre dépôt GitHub.
  3. Si vous avez déjà installé une version de test, installez la mise à jour par-dessus, sans désinstaller l’ancienne.
  4. Ouvrez PokeTool Test. Vous pouvez explorer la carte sans compte et créer un compte de test avec votre e-mail.

Cette version utilise un environnement de test. La connexion Google est limitée aux comptes autorisés. Ne publiez pas d’informations privées ou de signalements réels dans la bêta. L’APK ne s’installe pas sur iPhone.

Votre mission de testeur

Vérifiez la nouvelle identité, l’accueil, la navigation, la carte, les filtres, le compte et les signalements de test. Après chaque anomalie, notez le modèle du téléphone, la version Android, l’action effectuée et le résultat obtenu. Masquez vos informations personnelles dans les captures.
