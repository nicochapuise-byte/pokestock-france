# PokéStock France

Application communautaire pour localiser les produits Pokémon disponibles dans les magasins en France.

## Stack
- Next.js + TypeScript
- Tailwind CSS
- React Leaflet / OpenStreetMap
- Structure prête pour Supabase

## Lancer le projet
```bash
npm install
npm run dev
```
Puis ouvrir http://localhost:3000.

## Supabase
Copier `.env.example` vers `.env.local` et renseigner les variables lorsque le projet Supabase sera créé.
