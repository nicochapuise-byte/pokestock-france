# PokéStock France — version HTML simple

PokéStock France est une démo de site communautaire permettant de repérer des produits Pokémon signalés comme disponibles dans des magasins français.

## Aucun environnement de développement nécessaire

Cette version n'utilise plus Next.js, npm, TypeScript ou Tailwind.

Pour tester le site :

1. Télécharger le dépôt en ZIP.
2. Décompresser le dossier.
3. Double-cliquer sur `index.html`.

Une connexion internet est uniquement nécessaire pour charger la carte OpenStreetMap/Leaflet et les images de démonstration.

## Fichiers

- `index.html` : structure du site
- `styles.css` : design et responsive
- `script.js` : carte, filtres, recherche, formulaire et stockage local

## Fonctions de la démo

- carte interactive de France ;
- marqueurs de stocks ;
- recherche ville / magasin / produit ;
- filtres par série ;
- cartes de disponibilités ;
- formulaire "Signaler un produit" ;
- ajout d'une photo avec aperçu ;
- sauvegarde locale des signalements dans le navigateur ;
- bouton de géolocalisation quand le navigateur l'autorise.

## Important

Les données affichées au départ sont des données de démonstration. Le projet est communautaire et n'est pas affilié à Nintendo, Game Freak ou The Pokémon Company.
